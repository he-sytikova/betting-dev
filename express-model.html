Ежедневный анализ матчей текущего дня (по МСК) на предмет двойников с перевесом над линией букмекера. Кандидаты — только двойные шансы (1X, 12, X2) и тоталы голов (ТБ/ТМ) по внутренней модели исходов; чистые победы П1/П2 в экспрессы не допускаются. В отбор идут события с вероятностью от 60%, для которых доступен кэф Euro365 и EV = вероятность модели × кэф не ниже 0.97; диапазон 0.97–1.00 — нейтральная зона (не строгий value, а допуск на погрешность модели), строгий value начинается с EV ≥ 1.00 и выделяется жирным; в один экспресс попадают два события из разных матчей с максимальным суммарным EV, суммарный кэф ограничен сверху (до 4.00). Совместная вероятность — произведение вероятностей плеч (матчи разные, корреляция не учитывается), справедливый коэффициент — 1/p по модели. Кэфы — лучшая доступная цена из двух источников: Euro365 (интрадей-линия одного букмекера) и football-data.co.uk fixtures (консенсус Max/Avg по букмекерам, снимок после открытия рынка, обновляется несколько раз в неделю; двойного шанса там нет — эти плечи только по Euro365); наведение на кэф показывает цены по источникам. Кэфы используются только для отбора и отображения и не смешиваются с вероятностями модели. Если кэфы недоступны, страница работает в режиме максимальной вероятности. Прогноз рассчитывается только если лига и обе команды найдены в обучающих данных; иначе матч не участвует. Это исследовательская оценка вероятностей, а не рекомендация к ставке.
