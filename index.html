Кэфы дня — цены источников для анализируемых матчей (Euro365 · The Odds API · FDO)

Загрузка кэфов…
E365 — текущая интрадей-цена одного букмекера Euro365 (1X2 · Х · П2, двойные шансы, тоталы ТБ/ТМ); TOA — лучшая цена (Max) The Odds API по европейским букмекерам (только тоталы, только клубные лиги дня; консенсус Avg — в подсказке по наведению); FDO — консенсус открытия рынка football-data.co.uk (Avg), справочно: снимок после открытия, цены могли уйти. Показаны только основные линии тоталов (1.5 / 2.5 / 3.5). Цены справочные: в расчёт вероятностей модели они не входят. Матч без единой цены не показывается.

Активная страница

Голы и основные рынки

Внутренняя модель: исходы 1X2, двойные шансы, общий и индивидуальные тоталы голов (ТБ/ТМ). Каждая вероятность в отдельной строке с градиентной подсветкой.

 Активная страница

Угловые и жёлтые карточки

Внутренняя модель: тоталы угловых и жёлтых карточек (ТБ/ТМ) с построчным отображением и градиентной подсветкой вероятностей.

 Активная страница

Фолы, удары, удары в створ

Внутренняя модель: тоталы фолов, ударов и ударов в створ (ТБ/ТМ). Прогноз показывается только для матчей, найденных в обучающих данных.

 Активная страница

Экспрессы дня

Ежедневный отбор топ-5 двойников из самых вероятных событий дня: только двойные шансы и тоталы голов по внутренней модели, плечи из разных матчей.

 Экспериментальная страница

Еврокубки

Отдельная модель Лиги чемпионов, Лиги Европы и Лиги Конференций: единый кросс-страновой Elo по матчам всех трёх турниров плюс состояние команд в чемпионатах. Без проверки против рынка.

 Экспериментальная страница

Лига наций

Отдельная модель сборных: Elo по всей истории международных матчей с 1872 года, затухающие рейтинги атаки/защиты и форма. Без проверки против рынка.

 Активная страница

Прогнозы на завтра

Матчи завтрашнего дня (МСК) глазами всех внутренних моделей: клубные лиги, еврокубки, Лига наций. Расписание обновляется каждые 2 часа; только вероятности, без кэфов.

Экспериментальная среда. Результаты моделей требуют дальнейшей проверки и не являются рекомендацией для ставок.
